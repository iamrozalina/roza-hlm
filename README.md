# ГОРЯЧАЯ ЛИНИЯ МАЙАМИ (GameMaker 7-to-8.1 decomp)
Repository maintained by [iamrozalina](https://github.com/iamrozalina).<br/>
Not to be confused with [Pi0h1's repository](https://github.com/Pi0h1/HotlineMiami.gmx).<br/>


You're more than free to use this codebase for your own projects, be it forks or standalone projects as long as they stay non-profit. It should work* with [Instance](https://github.com/groverburger/instance), but I heavily recommend using GameMaker 8.1 instead since Instance is still a fairly young project and has some missing QOL features from GameMaker that you will miss.<br/>

Documentation coming soon (maybe).<br/>
When submitting an Issue regarding a bug or glitch, be sure to mention what OS and compatibility layers (if you're using any) you're running the project on. Otherwise your Issue will be closed.<br/>
Do keep in mind that this codebase will be targeted towards GameMaker 8.1 for obvious reasons.
