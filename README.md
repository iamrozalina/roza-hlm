# ГОРЯЧАЯ ЛИНИЯ МАЙАМИ (GameMaker 7-to-8.1 decomp)
Repository maintained by [iamrozalina](https://github.com/iamrozalina).<br/>
Not to be confused with [Pi0h1's repository](https://github.com/Pi0h1/HotlineMiami.gmx).<br/>


You're more than free to use this codebase for your own projects, be it forks or standalone projects as long as they stay non-profit. It should work fine with GameMaker 8.1, but I heavily recommend using [Instance](https://github.com/groverburger/instance) instead since it's built with pure Rust and uses APIs that play better with modern Windows or Linux PCs.<br/>

Documentation coming soon (maybe).<br/>
When submitting an Issue regarding a bug or glitch, be sure to mention what OS and compatibility layers (if you're using any) you're running the project on. Otherwise your Issue will be closed.
